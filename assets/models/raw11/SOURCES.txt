raw11 model sources: deep-water sharks + megalodon (compiled 2026-09-28). glTF 2.0 GLB with embedded PNG textures
(base colour 1024 px, megalodon 2048 px; normal and ORM 1024 px). Metallic-roughness PBR, no Draco/KTX2, no extensions.
Units: metres. Up: +Y. Head: +Z. Centred at the origin (bbox centre). Left side of the animal = +X. One mesh / one material each,
double-sided. None of the models is rigged or animated: the game swims static meshes procedurally along +Z.
Downloaded from the Objaverse mirror of Sketchfab CC-licensed models (https://huggingface.co/datasets/allenai/objaverse).
The licence was checked twice: the Objaverse annotation "license" field (= "by") and the file's own glTF asset.extras.license
("CC-BY-4.0 (http://creativecommons.org/licenses/by/4.0/)").
CC-BY 4.0 requires attribution in the game credits plus a note that the file was modified.

Processing (all three): blender/deepsharks.py (a copy of blender/deepspecies.py with three additions:
  --keep-mats  keeps mesh parts of every material and bakes each material's own colour (multi-atlas scans, eyes);
  --debruise   desaturates reddish post-mortem bruising in the baked base colour towards the surrounding skin tone;
  --samples=N  preview render samples.)
  blender --background --factory-startup --python blender/deepsharks.py -- <key>_src.glb <key>.glb <length_m> [flags] [--preview=<png>]
  (Blender 5.2, absolute output paths; bakes and previews with Cycles on the CPU only)
  Common modifications: removed the colour-checker cube; joined the parts, welded seams, removed floating fragments; baked all
  transforms; scaled to the stated length; head -> +Z, dorsal -> +Y; centred; decimated; new UV layout (smart UV project);
  smooth normals; source colour re-baked onto the new UVs; tangent-space normal map baked from the full-resolution source
  (clamped to <= 70 deg); AO baked into ORM.R; metallic 0, roughness 0.5-0.75 from texture luminance; double-sided.

megalodon_rigged.glb (2026-09-28) - rigged + animated derivative of megalodon.glb above.
  Credit line: "Megalodon" by phonlaphat, CC-BY 4.0, modified (rig, animation, teeth, mouth lining added for this project).
  Build: blender/megalodon_rig.py megalodon.glb megalodon_rigged.glb --preview=megalodon_rigged_preview.png (Blender 5.2, CPU only)
  Modifications:
  - rotated 180 deg about up: head now at glTF +Z (snout z=+10), +Y up, bbox centred, scaled x1.25 to 20.0 m long.
  - glTF UV-seam vertex splits merged; custom normals cleared (smooth shading).
  - teeth: the sculpt has a real mouth pocket but no teeth. 157 serrated triangular teeth (front row, upper + lower jaw,
    ~8 cm tall at the front tapering toward the gape corners, blade tips curled lingually, slanted distally) modelled
    procedurally along lip margins found by ray casts through the gape. Material 'megalodon_teeth' (enamel white,
    roughness 0.25, metallic 0).
  - mouth: the pocket (palate/floor) faces -> material 'megalodon_mouth' (same base texture x dark red-pink factor,
    roughness 0.45); two skinned cheek membranes added inside the lateral gape so the opened jaw shows a closed mouth
    cavity (no see-through).
  - skin material 'megalodon_skin': base colour 2048 + normal 1024 kept, ORM 1024 rebuilt (AO kept, roughness remapped to
    0.55-0.70, metallic 0).
  - armature: root, head, spine_01..04, tail_01, caudal_fin (spine chain), jaw (hinge near the gape corners), upper_jaw
    (small protrusion), pectoral_L/R_root + _mid. Spine weights = bone-heat automatic weights (computed on a voxel-remeshed
    proxy and transferred back); jaw / upper jaw / pectorals / teeth / membranes weighted explicitly.
  - clips 'Swim' and 'Gape', 77 frames @ 24 fps (3.208 s), exact loops; identical body motion (travelling tail sweep,
    head counter-yaw, pectoral trim); Gape adds a ~30 deg jaw opening + slow close, upper-jaw protrusion, pectorals lowering.
  46.4k triangles (skin 33.7k, mouth 6.2k, teeth 6.6k).
