raw13 model sources: school / deep-sea fish set + tuna mouth fix (compiled 2026-09-28). glTF 2.0 GLB with embedded PNG textures
(base colour + normal + ORM; 1024 px for kingfish / anglerfish, 512 px for sardine / cutlassfish / lanternfish / hatchetfish).
Metallic-roughness PBR, no Draco/KTX2, no extensions. Units: metres. Up: +Y. Head: +Z. Centred at the origin (bbox centre).
Left side of the animal = +X. One mesh / one material each, double-sided, static (no rig) - except tuna.glb (see below).
ORM: R = ambient occlusion, G = roughness, B = metallic. Silver fish carry metallic 0.6-0.8 / roughness 0.22-0.3 on the bright,
unsaturated (silver) texels; dark / coloured texels (backs, yellow fins, eyes) stay dielectric (metallic 0, roughness 0.5-0.75).
Downloaded from the Objaverse mirror of Sketchfab CC-licensed models (https://huggingface.co/datasets/allenai/objaverse).
The licence was checked twice: (1) the Objaverse annotation "license" field (= "by" for all) and (2) the file's own glTF
asset.extras.license ("CC-BY-4.0 (http://creativecommons.org/licenses/by/4.0/)" for all). Third check (Sketchfab API,
2026-09-28): the ffish.asia models have since been re-licensed to CC0 on Sketchfab; they are still credited here under the
CC-BY 4.0 terms they were downloaded under. CC-BY 4.0 requires attribution in the game credits plus a note that the file was modified.

Processing (all six static fish): blender/fishset.py (a copy of blender/deepsharks.py / deepspecies.py, extended with:
  --jaw=hz,hy,tz,ty,deg  closes an open mouth on the full-resolution source before decimating / baking;
  --silver=lo,hi,metal,rough  silver scales -> metallic/roughness in the ORM (B channel = metallic);
  --grade=sat,gain  desaturate / darken a painted base colour; --roll, --drop-mats, --cage/--ray bake distances;
  two-pass bake with sentinel fill (texels the first ray pass misses are re-baked with a 4x ray, the rest flood-filled),
  UV island packing, armature poses applied for rigged sources, low-poly bbox re-centred and scaled to the exact length,
  --probe=<png> Workbench head close-up used to measure the jaw hinge.)
  blender --background --factory-startup --python blender/fishset.py -- <key>_src.glb <key>.glb <length_m> [flags] [--preview=<png>]
  (Blender 5.2, Windows paths from WSL via wslpath -w; bakes and previews with Cycles on the CPU only, probes with Workbench)
  Common modifications: removed the colour-checker cube; joined the scan chunks (all texture atlases), welded seams, removed
  floating scan fragments; baked all transforms; head -> +Z, dorsal -> +Y; lateral bend removed (--straighten); centred;
  decimated to the triangle budget; new UV layout (smart UV project + pack); smooth normals; source colour re-baked onto the new
  UVs; tangent-space normal map baked from the full-resolution source (clamped to <= 70 deg); AO baked into ORM.R; roughness from
  texture luminance; metallic from the silver mask (silver fish); scaled to the stated length; double-sided.
  Head direction check: every output was re-imported in Blender and a Workbench close-up of its glTF +Z end rendered from +X
  (the animal's left flank): the head (eye, snout, mouth) is at +Z in all of them; mouth state checked on the same close-ups.
