raw9 model sources: deep-sea species variety set (compiled 2026-09-28). glTF 2.0 GLB with embedded PNG textures (base colour, normal
and ORM, all 1024 px). Metallic-roughness PBR, no Draco/KTX2, no extensions. Units: metres. Up: +Y. Head: +Z. Centred at the origin
(bbox centre). Left side of the animal = +X. One mesh / one material each, <= 25k triangles, double-sided.
Downloaded from the Objaverse mirror of Sketchfab CC-licensed models (https://huggingface.co/datasets/allenai/objaverse).
The licence was checked twice: the Objaverse annotation "license" field (= "by") and the file's own glTF asset.extras.license
("CC-BY-4.0 (http://creativecommons.org/licenses/by/4.0/)").
CC-BY 4.0 requires attribution in the game credits plus a note that the file was modified.
None of the models is rigged or animated. The game swims static meshes procedurally along +Z.

Processing (all six): blender/deepspecies.py
  blender --background --factory-startup --python blender/deepspecies.py -- <key>_src.glb <key>.glb <length_m> [flags] [--preview=<png>]
  (Blender 5.2, absolute output paths; bakes and previews with Cycles on the CPU only)
  Common modifications:
    - removed the colour-checker cube (non-dominant material) or the 12-triangle helper cubes; joined the scan chunks, welded seams,
      removed floating scan fragments;
    - baked all transforms; scaled to the real species length; head -> +Z, dorsal -> +Y; centred at the origin;
    - decimated to <= 25k triangles; new UV layout (smart UV project); smooth normals;
    - scan texture re-baked onto the new UVs (1024 px, the source textures are 1024 px); tangent-space normal map (1024 px) baked from the
      full-resolution source (normals on thin fins / legs clamped to <= 70 deg against back-face bake errors); ambient occlusion baked into ORM.R;
    - unlit / plain scan material -> metallic-roughness: metallic 0, roughness 0.5-0.75 from texture luminance (gulper eel: flat colour,
      roughness 0.5-0.7), double-sided.
